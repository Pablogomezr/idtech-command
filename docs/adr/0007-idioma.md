# ADR 0007 — Idioma del código y la documentación

- Estado: aceptada (2026-10-26)

Interfaz, documentación, base de datos e identificadores de código en español (Colombia).
En identificadores: sin tildes ni ñ, `snake_case` (`retencion_contratada_dias`, `anio`).
Razón: el contrato con el cliente, el informe de SLA y el código usan las mismas palabras, y
quien mantiene el proyecto piensa en español. Las librerías externas conservan su inglés.
